1.6 Desirable Qualities of an Operating System

The desirable qualities are grouped into four areas: Usability, Facilities, Cost, and Adaptability.

1. Usability

  • Robustness: Accept all valid inputs and handle them gracefully.
  • Consistency: Behaviour should be uniform and predictable.
  • Proportionality: Resources and complexity should be proportional to the user's needs.
  • Convenience: Easy to use and intuitive.
  • Powerful with high‑level facilities: Provide powerful, user‑friendly tools.

2. Facilities

  • Sufficient for intended use: Must meet user requirements.
  • Complete: Include all necessary functions.
  • Appropriate: Features match the target environment.

3. Costs

  • Low cost and efficient services.
  • Good algorithms: Make use of space/time tradeoffs, special hardware.
  • Low overhead: Cost of doing nothing should be low (e.g., idle time at a terminal).
  • Low maintenance cost: System should not require constant attention.

4. Adaptability

  • Tailored to the environment: Support necessary activities; do not impose unnecessary restrictions. Make the most common tasks easy.
  • Changeable over time: Adapt as needs and resources change (e.g., expanding memory, new devices, new user population).
  • Extendible / Extensible: Adding new facilities and features that look and feel like existing ones.

1.7 Operating Systems: Some Examples

1.7.1 DOS (Disk Operating System)

  • First widely‑installed OS for personal computers.
  • Master control program that runs automatically when you start your PC.
  • Single‑user operating system from Microsoft.
  • Underlying control program for Windows 3.1, 95, 98, ME. Windows NT, 2000, and XP emulate DOS to support existing DOS applications.

1.7.2 UNIX

  • Used in widely‑sold workstation products (Sun, Silicon Graphics, IBM, etc.).
  • The UNIX environment and client/server model were vital in developing the Internet.
  • Written in C. Both UNIX and C developed by AT&T and distributed to government/academia, causing wide portability – synonymous with “open systems”.
  • Structure: kernel, file system, shell (command line interface). Major shells: Bourne, C shell, Korn shell.
  • Over 600 commands; Motif GUI provides a friendlier image.
  • Widely used in mission‑critical client/server and transaction processing. Versions: Sun Solaris, Digital UNIX, HP HP‑UX, IBM AIX, SCO UnixWare. IBM mainframes run UNIX via added interfaces to MVS/OS390.
  • Linux, a UNIX derivative, is gaining popularity as a free/commercial alternative.

1.7.3 WINDOWS

  • Personal computer OS from Microsoft; with MS Word/Excel, became de facto standard in corporations and homes.
  • Built‑in networking allows sharing files and applications. In enterprises, Windows clients often connect to UNIX/NetWare servers. Server versions (Windows NT, 2000) provide a Windows‑only client‑server solution.
  • Supported by Microsoft and tens of thousands of developers.
  • Networking support is the main reason for its success.
  • Complicated environments; certain hardware/software combos cause problems, troubleshooting can be daunting. Interface changes between versions confuse users.
  • Microsoft worked to improve resilience in Windows 2000/XP against installation problems and crashes.

1.7.4 MACINTOSH (Mac)

  • Introduced in 1984 by Apple Computer; first widely‑sold personal computer with a graphical user interface (GUI).
  • Designed to be natural, intuitive, and user‑friendly – introduced mouse, icons, point‑and‑click, click‑and‑drag, window operations.
  • Microsoft adapted these concepts in Windows.
  • Disadvantage: fewer applications than Windows, but all fundamental ones exist. Data compatibility between Windows and Mac is solvable.
  • Own OS: Mac OS (latest version Mac OS X). Originally on Motorola 68000, now on PowerPC (Apple, Motorola, IBM).
  • Mac users about 5% of total PC users, but highly popular among graphic designers, online visual artists, and their companies.

1.7 (Concluding Note) – Users of the Operating System

Users of operating system can be divided into two broad classes:

  • Command language users: Interact with the OS using commands (e.g., shell commands).
  • System call users: Invoke OS services by means of runtime system calls during program execution (programmatic interface).

📋 Summary of Desirable Qualities & OS Examples

A quality OS focuses on Usability (robust, consistent, proportional, convenient, high‑level facilities), Facilities (sufficient, complete, appropriate), Cost (low cost, efficient, low overhead, low maintenance), and Adaptability (tailored, changeable, extensible).

DOS was the first widely‑installed PC OS, single‑user, and underlay early Windows. UNIX, written in C, became synonymous with open systems, influencing the Internet, with variants like Linux, Solaris, and AIX. Windows achieved dominance through built‑in networking and a vast software ecosystem, though complexity remains a challenge. Macintosh pioneered the GUI and remains a staple in creative industries. OS users are either command language users or system call users.
