📘 Detailed Notes

1.1 Software Categories

Application Software: Programs that perform specific tasks for users. Designed to solve a particular problem. Examples: spreadsheets, database systems, desktop publishing, program development software, games.

System Software: More transparent to users; provides a general programming environment where programmers create applications. It offers functions not available at hardware level and manages execution of application programs. Acts as an interface between computer hardware and application software.

Key role: The most important type of system software is the Operating System (OS).

1.2 Operating System – Core Definition

Operating System (OS): A collection of programs that acts as an interface between the user of a computer and the computer hardware. Its purpose is to provide an environment in which a user may execute programs.

OS as a Resource Manager: The main resource is computer hardware – processors, storage, I/O devices, communication devices, and data. The OS manages these and allocates them to programs and users. Because many requests may conflict, the OS must decide fairly and efficiently.

Some OS functions (from resource management perspective):

  • Implementing the user interface
  • Sharing hardware among users
  • Allowing users to share data
  • Preventing users from interfering with one another
  • Scheduling resources among users
  • Facilitating input/output
  • Recovering from errors
  • Accounting for resource usage
  • Facilitating parallel operations
  • Organizing data for secure and rapid access
  • Handling network communications

1.3 What is an Operating System? – Expanded

Four main components of a computer system:

  1. Hardware – provides basic computing resources (CPU, memory, I/O devices).
  2. Operating System – controls and coordinates the use of hardware among various application programs and users.
  3. Application Software – defines the way in which hardware resources are used to solve user problems.
  4. Users – people, machines, or other computers.

Abstract View (Figure 1): Users interact with Application Software. Application Software relies on the Operating System. The Operating System directly manages the Hardware. The OS sits between users/applications and the bare machine.

OS as a Resource Allocator: A computer system has many resources – CPU time, memory space, file storage, I/O devices. The OS acts as the manager, allocating these to specific programs and users. It must resolve conflicting requests fairly and efficiently.

OS as a Control Program: Controls the execution of user programs to prevent errors and improper use of the computer. It ensures that the system operates correctly and protects against malicious or accidental interference.

Two Basic Purposes of an Operating System (Working Definition)

  1. Resource allocation and control: To control the allocation and use of the computing system’s resources among various users and tasks.
  2. Interface and development support: To provide an interface between the computer hardware and the programmer that simplifies and makes feasible the creation, coding, debugging, and maintenance of application programs.

Functions an Effective Operating System Should Accomplish

  • Command interpreter: Provide a user-friendly environment (shell, GUI).
  • Communication: Facilitate communication with other users (e.g., networking).
  • File management: Facilitate directory/file creation along with security options.
  • I/O handling: Provide routines that manage the intricate details of I/O programming.
  • Language translation access: Provide access to compilers to translate high-level languages to machine code.
  • Loader: Supply a loader program to move compiled code into memory for execution.
  • CPU scheduling: Ensure that when several active processes exist, each gets fair and non-interfering access to the CPU.
  • Storage and device allocation: Take care of storage (memory) and device allocation.
  • Long-term storage: Provide for long-term storage of user information in the form of files.
  • Resource sharing and protection: Permit system resources to be shared among users when appropriate, and protect them from unauthorized or mischievous intervention.

Note: Systems programs (editors, translators, utilities like sort and file transfer) are not usually considered part of the OS, but the OS is responsible for providing access to them.

📋 Summary

Software is divided into application software (user-oriented problem solvers) and system software (environment providers). The Operating System is the core system software, acting as an interface between hardware and users/applications. It is both a resource allocator (managing CPU, memory, storage, I/O) and a control program (preventing errors and improper use). An effective OS provides a user interface, handles I/O, ensures fair CPU scheduling, manages files and security, supports program development (compilers, loaders), enables sharing and protection of resources, and recovers from errors. The abstract structure places the OS between application software and hardware, coordinating all activities. These notes capture the complete introductory framework, fulfilling the unit's objectives for definitions, purposes, and functions of an operating system.
